# Promethee Pomodoro 1.0.1 release

**Status:** Public-release candidate pending the complete three-target smoke matrix and exact npm/GitHub readback.

Version 1.0.1 is the first publishable Promethee Pomodoro release. It contains the complete product scope documented in the [1.0.0 candidate notes](v1.0.0.md), while preserving the failed `v1.0.0` tag as immutable evidence.

The first run successfully validated source and built macOS arm64, macOS x64, and Windows x64 helpers. Publication remained blocked because clean-package smoke found two release-only defects: the macOS launcher ignored its isolated installation directory, and the Windows readiness check depended on GUI-process stdout. Version 1.0.1 passes the install directory explicitly and writes the Electron readiness marker to a bounded caller-selected result file.

No npm or GitHub Release claim is valid until the `v1.0.1` workflow, registry integrity, `latest` dist-tag, and release-asset readbacks all pass. The package remains unsigned and unnotarized; Windows automatic Pause/Resume remains unavailable by design.
