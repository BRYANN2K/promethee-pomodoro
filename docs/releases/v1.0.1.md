# Promethee Pomodoro 1.0.1 release

**Status:** Released publicly on 2026-08-26.

Version 1.0.1 is the first public Promethee Pomodoro release. It contains the complete product scope documented in the [1.0.0 candidate notes](v1.0.0.md), while preserving the failed `v1.0.0` tag as immutable evidence.

The first run successfully validated source and built macOS arm64, macOS x64, and Windows x64 helpers. Publication remained blocked because clean-package smoke found two release-only defects: the macOS launcher ignored its isolated installation directory, and the Windows readiness check depended on GUI-process stdout. Version 1.0.1 passes the install directory explicitly and writes the Electron readiness marker to a bounded caller-selected result file.

Release run `32966038040` passed source validation, all three native builds, exact installed-package smoke on macOS arm64, macOS x64, and Windows x64, npm integrity/`latest` readback, and GitHub asset readback. npm publishes `promethee-pomodoro@1.0.1`; GitHub publishes the matching `v1.0.1` tarball and `SHA256SUMS`. The tarball SHA-256 is `9ba4d339b16f3adcb0cd249890e615b57f99cbe45ed4c229bfad32367a5a51d9`. The package remains unsigned and unnotarized; Windows automatic Pause/Resume remains unavailable by design, and the package smoke is not a live Windows Promethee exercise.
